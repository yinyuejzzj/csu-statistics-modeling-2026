# 城镇化进程与省级出生率分化

> 2026 年（第十二届）全国大学生统计建模大赛 · 本科生组参赛作品
> 作品编号：TJJM20260428282056

## 一句话概括

用 **XGBoost 筛变量 → 面板双向固定效应定因果 → 分位数回归看异质性** 的三段式框架，把 2010—2022 年 31 个省级行政区、403 个观测的面板数据跑了一遍，回答一个问题：**城镇化推进到底在多大程度上压低省级出生率，以及这个影响在"本来就生得少"的省份和"还生得动"的省份之间差多少**。

结论：城镇化率每提高 1 个百分点，省级出生率平均下降约 **0.05‰—0.27‰**（三种模型规格下均显著为负）；而且**低出生率省份受伤更重**——第 10 分位系数 −0.317，第 90 分位只有 −0.135。也就是说，东部这些已经跌破低位的省份，城镇化再往前走一步，出生率的下行压力比西部大得多。收入的作用则是非线性的，在不同分位点上方向会翻转。

## 方法

**阶段一 · 变量筛选（非参数）**
把城镇化率、人均可支配收入、收入对数、时间趋势、省份编码、区域编码 6 个候选变量输入 XGBoost（200 棵树、depth=4、lr=0.05），按分裂节点对损失函数的贡献（F-score）排序。结果：城镇化率 **0.337** 居首，省份固定效应 0.211、时间趋势 0.209、区域效应 0.190，收入对数仅 0.054。

**阶段二 · 因果识别（参数）**

```
BirthRate(i,t) = α + β1·Urbanization(i,t) + β2·ln(Income(i,t)) + μi + λt + ε(i,t)
```

三档规格：模型 1 仅省份固定效应；模型 2 加入收入对数；模型 3 双向固定效应（主模型）。标准误在省份层面聚类。

**阶段三 · 异质性（分位数回归）**
在 τ = 0.10 / 0.25 / 0.50 / 0.75 / 0.90 五个分位点上分别估计城镇化率与收入的边际效应，并做东/中/西分区域回归作为稳健性检验。

## 主要结果

**面板固定效应（表 2）**

| 变量 | 模型 1（省份 FE） | 模型 2（省份 FE+收入） | 模型 3（双向 FE） |
| --- | --- | --- | --- |
| 城镇化率 | −0.199*** | −0.272*** | −0.050** |
| 95% CI | [−0.232, −0.166] | [−0.375, −0.168] | [−0.098, −0.002] |
| 收入对数 | — | 1.411 | 0.768 |
| 组内 R² | 0.418 | 0.431 | 0.053 |

模型 3 系数收窄是合理现象：全国性的下行趋势已被时间哑变量吸收，剩下的 −0.050 只识别"各省城镇化推进速度差异"带来的生育差距。

**分位数回归（异质性）**

| 分位点 | 城镇化率系数 | 收入对数系数 |
| --- | --- | --- |
| Q10 | −0.317 | +8.31 |
| Q25 | −0.241 | +5.32 |
| Q50 | −0.191 | +3.70 |
| Q75 | −0.115 | −0.13 |
| Q90 | −0.135 | +1.35 |

城镇化率的抑制效应随分位点上升而收窄，说明**低生育率省份对城镇化的推进更敏感**；收入效应则呈非单调变化——低分位区财富效应占优，随分位上升机会成本效应显现，到高分位又出现符号波动，两种机制相互抵消。

**稳健性**：东/中/西分区域重估，城镇化率系数在三组样本中均显著为负，东部绝对值最大，与分位数回归揭示的方向一致。

## 复现

```bash
python -m pip install -r code/requirements.txt
cd code
python get_data.py      # 生成 panel_data.csv
python model.py         # 重新生成 fig1—fig4 与回归结果表
```

`get_data.py` 内置了从年鉴整理出的 2010/2015/2020/2022 四个年份节点数据，缺失年份按线性插值补全，因此单独运行即可得到完整面板，不依赖外部下载。

环境：Python 3.10，pandas 2.0，xgboost 1.7，linearmodels 5.3，statsmodels 0.14，matplotlib 3.7。`model.py` 里中文字体设为 `Noto Sans CJK JP`，在 Windows 上如遇中文方框，改成 `SimHei` 即可。
